SQS

Amazon Simple Queue Service

SDK name
sqs
API operations
23
Size rank
#264 of 436

What it is

Simple Queue Service: a queue that holds messages until a worker takes them.

What it is for

Smoothing out bursts of work and decoupling parts of an app.

The catch

Standard or FIFO, visibility timeouts, dead-letter queues: each choice changes how failures behave.
