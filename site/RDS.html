RDS

Amazon Relational Database Service

SDK name
rds
API operations
168
Size rank
#10 of 436

What it is

Managed relational databases: PostgreSQL, MySQL, MariaDB, Oracle, SQL Server, IBM Db2, and Amazon Aurora.

What it is for

Apps that need SQL, joins and transactions.

The catch

You still choose instance sizes, storage, backups, Multi-AZ, networking (a VPC and subnets) and maintenance windows.

For a website

Only if your site stores data. A whole site on Shadw is one file →
