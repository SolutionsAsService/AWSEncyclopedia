Lambda

AWS Lambda

SDK name
lambda
API operations
88
Size rank
#56 of 436

What it is

Functions that run when something happens (a web request, a file upload, a message) without a server you manage. You pay per request and per millisecond.

What it is for

Small pieces of backend logic, glue between services, scheduled jobs.

The catch

Each function needs an IAM role, a trigger and limits (time, memory); a web API usually adds API Gateway or a function URL. Debugging spans CloudWatch logs.

For a website

Not needed for a site that is only pages. A whole site on Shadw is one config file →
