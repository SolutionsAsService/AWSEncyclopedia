IAM

AWS Identity and Access Management

SDK name
iam
API operations
180
Size rank
#8 of 436

What it is

Identity and Access Management: users, roles and JSON policies that say who may do what to which resource.

What it is for

Every AWS account, from the first day.

The catch

Every service has its own actions to allow or deny, and a wrong policy is either a security hole or an access-denied error. IAM's own API has more operations than most services.
