ElastiCache

Amazon ElastiCache

SDK name
elasticache
API operations
77
Size rank
#70 of 436

What it is

Managed in-memory caches (Valkey, Redis OSS, Memcached).

What it is for

Making reads fast and taking load off a database.

The catch

Node types, clusters and replication (ElastiCache Serverless hides those), and a VPC to reach it from.

For a website

Not needed for a site that is only pages. A whole site on Shadw is one config file →
