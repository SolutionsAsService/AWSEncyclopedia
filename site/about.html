About this guide

A plain field guide to AWS, rebuilt in 2026.

Where the numbers come from

Every count on the site is read from the AWS SDK for Python (botocore 1.44.1, read 2026-11-12): one model per service API, the operations in each model, and the regions in its endpoint data. _src/fetch_aws.py refreshes them; _src/build.py writes the pages and fails if a service it names is missing.
