SNS

Amazon Simple Notification Service

SDK name
sns
API operations
42
Size rank
#153 of 436

What it is

Simple Notification Service: publish one message, deliver it to many subscribers (queues, functions, email, SMS, HTTP).

What it is for

Fan-out: one event, many reactions.

The catch

Delivery retries, filters and permissions per subscriber; easy to confuse with SQS and EventBridge.
