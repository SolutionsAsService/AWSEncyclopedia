EBS

Amazon Elastic Block Store

SDK name
ebs
API operations
6
Size rank
#382 of 436

What it is

Elastic Block Store: virtual disks for EC2 servers, usually attached to one (io1 and io2 volumes can attach to several).

What it is for

The hard drive of an EC2 instance; snapshots for backup.

The catch

Volume types, sizes, IOPS and snapshots. Most EBS actions live in the EC2 API; the separate EBS API reads and writes snapshot data directly.
