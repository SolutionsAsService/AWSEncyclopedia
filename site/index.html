Or skip all of it

To put a static site on your own domain by hand on AWS, you wire up to five services together (or use Amplify Hosting, which bundles them). On Shadw this whole site deploys with one small config file next to its pages:

{
  "project": "awsencyclopedia",
  "static_dir": "site",
  "routes": [{ "pattern": "/", "target": "static" }]
}
