DynamoDB

Amazon DynamoDB

SDK name
dynamodb
API operations
62
Size rank
#105 of 436

What it is

A key-value and document database that scales without servers. You design tables around the questions you will ask.

What it is for

High-traffic apps with simple, predictable lookups.

The catch

You must plan access patterns and keys up front; questions you did not plan for are slow or expensive.
