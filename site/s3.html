S3

Amazon Simple Storage Service

SDK name
s3
API operations
116
Size rank
#25 of 436

What it is

Object storage: files (“objects”) in named “buckets”, reached by URL or API, stored across several data centres.

What it is for

Uploads, backups, logs, data for analytics, and the files of static websites.

The catch

A bucket is private by default; making a website public means bucket policies, Block Public Access settings and usually CloudFront in front for HTTPS on your own domain.
