AWS Elastic Beanstalk

SDK name
elasticbeanstalk
API operations
47
Size rank
#136 of 436

What it is

AWS Elastic Beanstalk: upload an app and it creates the servers, load balancer and scaling for you, on EC2.

What it is for

Running a familiar web app (Node, Python, Java, …) without wiring every piece by hand.

The catch

The pieces it creates are still yours to pay for and understand when something breaks.
