EC2

Amazon Elastic Compute Cloud

SDK name
ec2
API operations
811
Size rank
#1 of 436

What it is

Virtual servers you rent by the second. You choose the size, the operating system and the network, and you look after everything on it.

What it is for

Anything that needs a full computer: a long-running app server, a game server, a build machine.

The catch

You own the server: patches, scaling, backups, and the security group that decides who can reach it. Its API is the largest in AWS.
